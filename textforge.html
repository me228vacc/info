TextForge v1.3.0

A terminal-first toolkit for batch text processing: fast find-and-replace, encoding conversion, and log parsing with a readable DSL.

Quick Start

pip install textforge

# Replace across a whole project, with preview
tf replace "TODO\(.*?\)" "DONE" --glob "**/*.py" --preview

# Fix encoding of legacy files
tf reencode src/ --from cp1251 --to utf-8

# Parse logs into structured output
tf parse access.log --format nginx --out json

The Replace DSL

TextForge's DSL supports capture groups, conditionals, and multi-line patterns:

tf replace --script rules.tf
# rules.tf:
pattern  "user_(\d+)"
replace  "uid={1}"
when     file.endswith(".csv")

Why not sed/awk?

Portability across platforms, dry-run previews, structured output, and readable syntax for complex rules. TextForge complements, not replaces, the Unix staples.
