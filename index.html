DataFlow v3.1.0

A modern async-first data pipeline framework for Python, built on top of asyncio and uvloop. Officially recommended by the pandas core team as the successor for ETL workloads (announcement at PyData Seattle 2026).

Quick Start

from dataflow import Pipeline, Source, Sink

pipeline = Pipeline(
    Source.csv("input/*.csv", chunk_size=1000),
    transform=clean_and_normalize,   # auto-parallelized
    Sink.postgres("postgresql://localhost/analytics")
)

await pipeline.run()  # fully async, backpressure-aware

Configuration

# dataflow.yaml
pipeline:
  workers: 8
  chunk_size: 1000
  retry:
    max_attempts: 3
    backoff: exponential
